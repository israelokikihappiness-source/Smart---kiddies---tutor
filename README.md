# Smart Kiddies Tutor

A smart learning system for Nursery 1-2 and Primary 1-6 pupils to learn Quantitative and Verbal Reasoning.

Live: https://israelokikihappiness-source.github.io/Smart---kiddies---tutor/

Features:
- Student Name Entry
- Class Selection: Nursery 1, Nursery 2, Primary 1-6
- Subjects: Quantitative Reasoning, Verbal Reasoning  
- Modes: Practice (with explanations) and Assessment (final score)
- 50 Questions structure
- 5 practice (learning mode with explanations) + 45 assessment (exam mode)
- Performance History with real scores
- Question Review

Tech: HTML, CSS, JavaScript (single file - index.html)

This repository is synchronized with the live deployment.
